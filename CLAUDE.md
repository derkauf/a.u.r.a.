## Regras de sessão

Dev notes: docs/dev-notes
Session repos: .
Derived docs: README.md, a.u.r.a.-by-lola-guia-inicial.pdf (generated by tools/generate-guia-pdf.py)

As skills de usuário `/resume` (`/retomar`) e `/devlog` (`/encerrar`) seguem estas linhas. Responda em português.

- **Início:** rode `/retomar`, ou leia `docs/dev-notes/PROGRESS.md` e `docs/dev-notes/RESUME.md`, e nada mais até a tarefa pedir. O PROGRESS linka o resto.
- **Durante:** registre cada decisão ou descoberta no arquivo certo (PROGRESS, o log da sessão, um doc em `docs/`) antes de seguir. Nada importante fica só na conversa.
- **`/devlog` (`/encerrar`)** fecha a sessão:
  1. Preencha `docs/dev-notes/templates/DEVLOG_TEMPLATE.md` e salve como `docs/dev-notes/chat-logs/AAAA-MM-DD-<tema>.md`. Se já houver um log do mesmo dia, atualize-o.
  2. Atualize o PROGRESS: Agora, Próximos, Esperando e uma linha em "Mudanças recentes" com o link do log. Passando de umas 10 linhas, mova as mais antigas para `docs/dev-notes/changelog/AAAA-MM.md`.
  3. Reescreva `docs/dev-notes/RESUME.md`, o handoff do próximo `/retomar`.
  4. Confira se os docs derivados ficaram desatualizados e **só relate**; edite-os apenas se o usuário pedir.
- **Log do build inicial:** `memory.md`, na raiz (14/11/2026). Os logs novos vão para `docs/dev-notes/chat-logs/`.
- **Fonte de verdade:** o repo oficial é `derkauf/a.u.r.a.`. Este projeto é uma variante para comparação; nada aqui deve tocar nele.
